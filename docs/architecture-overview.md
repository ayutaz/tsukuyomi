# Koe-Tatsu: 日本語音声合成システム アーキテクチャ概要

## プロジェクト概要

Koe-Tatsu（声達）は、最先端の表現力を持つ日本語音声合成システムです。本プロジェクトは、高品質な日本語音声合成を実現するため、最新の深層学習技術を統合したモジュラー型アーキテクチャを採用しています。

## 主要な要件

1. **最高峰のアクセント忠実度**: 日本語の複雑なピッチアクセントを正確に再現
2. **特定話者への最高峰の再現性**: キャラクター音声の高忠実度な再現
3. **正確かつ指定可能な感情表現**: 離散的・連続的な感情制御
4. **リアルタイムでの話者モーフィング**: 滑らかな話者間の音声ブレンド
5. **ONNXによる効率的なデプロイメント**: 低遅延・低コストでの推論

## アーキテクチャ設計思想

### モジュラー型設計の採用

VITSのようなEnd-to-End方式ではなく、各機能を独立したモジュールとして実装する設計を採用しました。これにより：

- 各モジュールの独立した最適化が可能
- 新技術への迅速な対応
- 長期的なメンテナンス性の向上
- 日本語特有の課題への特化した対応

## システム構成

```
[日本語テキスト入力]
     ↓
[1. 前処理層]
├─ MeCabによる形態素解析
├─ テキスト正規化
└─ 分かち書き処理
     ↓
[2. 音韻表現層]（ハイブリッド）
├─ XPhoneBERT: 多言語音素埋め込み（768次元）
└─ F0-BERT: 日本語韻律予測（F0系列）
     ↓ 特徴量統合
[3. 音響モデル層]
├─ 基盤: Matcha-TTS (CFM) / VITS
├─ 話者適応: Residual Adapters
└─ 感情制御: HVAE
     ↓ メルスペクトログラム/SSL特徴量
[4. 音声変換層]（オプション）
└─ kNNベースSSL特徴量補間
     ↓
[5. ボコーダー層]
└─ BigVGAN（高品質汎用ボコーダー）
     ↓
[音声波形出力]
```

## 実装フェーズ

### フェーズ1: 基本実装（現在）
- XPhoneBERT + 既存日本語VITS + BigVGAN
- 基本的な音声合成機能の実現
- 動作確認と基準性能の確立

### フェーズ2: 韻律強化
- F0-BERTによる日本語アクセント予測の実装
- XPhoneBERTとF0予測の統合
- 日本語音声品質の大幅向上

### フェーズ3: 高度な機能実装
- Residual Adaptersによる効率的な話者適応
- HVAEによる階層的感情制御
- CFM（Conditional Flow Matching）への移行
- kNNベースの音声モーフィング機能

## 技術選択の根拠

### XPhoneBERT
- 実装が明確で実績がある
- 多言語対応の基盤として有効
- 音素レベルの高品質な表現学習

### F0-BERT
- 日本語のピッチアクセントに特化
- ラベルフリーで直接F0を予測
- 未知語や連声にも対応可能

### BigVGAN
- 業界標準の高品質ボコーダー
- 多言語・多話者に対応
- 高速な推論が可能

### モジュラー設計
- 各コンポーネントの独立した開発・評価
- 新技術への迅速な対応
- ONNXへの効率的なエクスポート

## 期待される成果

1. **品質**: 日本語の自然なアクセントと高い明瞭度
2. **表現力**: 豊かな感情表現と話者の個性
3. **柔軟性**: 話者適応やモーフィングによる多様な音声生成
4. **実用性**: 低遅延・低コストでの実運用
